# Тестовое задание на должность "Фронтенд разработчик React"

React + TypeScript + Vite проект.

**В рамках задания решено было делать базовый минимум для работоспособности, а так же не тащить в проект сторонних библиотек**
- чистый css (придерживался методологии БЭМ)
- запросы через fetch api
- условный рендеринг вместо полноценного роутинга
- опущена семантика
- опущены accessibility
- опущены индикации загрузки
- не используются state-менеджеры или контекст (данные передаются через пропсы и localStorage)

**Что сделано:**
- базовая вёрстка, визуально приближенная к web.max.ru
- базовая обработка сетевых ошибок
- базовая валидация (на пустые поля)

В качестве помощника использовалась локальная модель Qwen3.6-35b-a3b

Готов объяснить любую часть кода и все архитектурные решения.

## Запуск проекта

**Требуемое окружение:**

- Node.js версии 20.19+ или 22.12+
- Пакетный менеджер
  - npm 9+
  - pnpm 8+ или 9+
  - Yarn: 3+ или 4+

```bash
npm install      # Установка зависимостей
npm run dev      # Запуск dev-сервера
```

## Текст тестового задания
```
Требования:
1. Требуется разработать пользовательский интерфейс для отправки и получения
сообщений в MAX
2. Требуется использовать сервис GREEN-API https://green-api.com/max
3. Требуется реализовать отправку и получение только текстовых сообщений
4. Требуется за прототип интерфейса взять внешний вид чата https://web.max.ru/
5. Требуется реализовать интерфейс максимально простым с минимальным набором
функций
6. Требуется отправку сообщений реализовать методом
https://green-api.com/v3/docs/api/sending/SendMessage/
7. Требуется получение сообщений реализовать методом
https://green-api.com/v3/docs/api/receiving/technology-http-api/
8. Требуется использовать технологию React
Ожидаемый результат:
· Пользователь переходит на сайт чата и вводит свои учетные данные из
системы GREEN-API (idInstance, apiTokenInstance)
· Пользователь вводит номер телефона получателя и создает новый чат
· Пользователь пишет текстовое сообщение и отправляет его получателю в MAX
· Получатель отвечает на сообщение в мессенджере MAX
· Пользователь видит ответ получателя в чате
```
